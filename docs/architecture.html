Stage 02

Tokenization & Boundaries

Module Source
tokenizer.py sentenceprocessor.py
Special Boundary Tokens
<START> & <END>
  • Buffer isolates punctuation as independent tokens.
  • Injects <START> to initiate Markov chains.
  • Injects <END> after period, question, exclamation.
  • Demarcates natural sentence terminations.
Stage 03

Bigram MLE Engine

Module Source
trainer.py bigram.py
P(w_i | w_{i-1}) = Count(w_{i-1}, w_i) / Count(w_{i-1})
  • Builds adjacent token transition frequency table.
  • Maximum Likelihood Estimation normalization.
  • Validates probability axioms: Σ P(w | context) = 1.0.
  • Compact JSON serialization (serializer.py).
Stage 04

Autoregressive Generation

Module Source
sampler.py generator.py
Sampling Controls
Temperature (T), Seed, Max Tokens
  • Inverse-transform roulette wheel sampling.
  • Temperature: Greedy (0.01) to Creative (1.5).
  • Generates from <START> until <END>.
  • Detokenizer restores natural punctuation spacing.
Stage 05

Intrinsic Evaluation

Module Source
evaluator.py
PP = exp(- 1/N * Σ ln P(w_i | w_{i-1}))
  • Measures vocabulary (17K) and bigrams (436K).
  • Test set coverage: 97.89% seen bigrams.
  • Cross-entropy log-probability across splits.
  • Zero-Frequency Trap: Unseen pair ⟹ PP = ∞.
