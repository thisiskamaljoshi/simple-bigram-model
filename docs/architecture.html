First-Principles Machine Learning

Statistical Bigram Language Model Architecture

A modular autoregressive next-token prediction pipeline built from scratch in pure Python with zero external machine learning dependencies.

✓ 70 Pytest Unit Tests ✓ 97.3% Code Coverage Zero Frameworks (No PyTorch / HuggingFace) Hugging Face TinyStories
Stage 01

Data Ingestion & Hashing

Module Source
download_corpus.py
Splitting Strategy
SHA-256 Story Bucketing
  • Streams raw text up to byte quota (50 MB or 500 MB).
  • Deterministic 80/20 train/test split at the story level.
  • Prevents train-test leakage across multi-sentence stories.
  • Atomic file rename (.tmp) prevents corruption.
Stage 02

Tokenization & Boundaries

Module Source
tokenizer.py + sentenceprocessor.py
Special Tokens
<START> & <END>
  • Custom character buffer separates words and punctuation marks.
  • Injects <START> to model sequence initiation.
  • Injects <END> after period, question mark, and exclamation marks.
  • Demarcates natural sentence terminations.
Stage 03

MLE Training Engine

Module Source
trainer.py + bigram.py
P(w_i | w_{i-1}) = Count(w_{i-1}, w_i) / Σ Count(w_{i-1}, w')
  • Counts frequency of all adjacent bigram pairs in corpus.
  • Applies Maximum Likelihood Estimation (MLE) normalization.
  • Validates probability axioms: Σ P(w | context) = 1.0.
  • Serialized to validated JSON model (serializer.py).
Stage 04

Autoregressive Generation

Module Source
sampler.py + generator.py
Sampling Controls
Temperature (T) & Seed
  • Inverse transform (roulette wheel) cumulative sampling.
  • Temperature scaling: Greedy (T=0.01) to Creative (T=1.5).
  • Runs autoregressively from <START> until <END>.
  • Punctuation-aware detokenizer restores natural spacing.
Stage 05

Intrinsic Evaluation

Module Source
evaluator.py
PP = exp(- 1/N * Σ ln P)
  • Measures vocabulary size and unique transition counts.
  • Computes unseen vs. seen test coverage (97.89%).
  • Calculates cross-entropy log-probability across splits.
  • Highlights Zero-Frequency Trap: Unseen pairs give Perplexity = ∞.
